1. MVP 구현 범위

아래는 제출 시점에 배포 URL에서 실제로 동작하는 기능만 기재했습니다. 미구현·예정 기능은 제외했습니다.

  • 현금흐름 예측 — 플랫폼별 정산 주기와 반복 지출을 학습해 향후 45일 잔액을 일 단위로 계산하고, 최소 안전잔액을 밑도는 날짜를 산출. 정산 지연·수입 감소 두 가지 가정 시나리오 비교 포함.
  • 세금·건강보험료 추정 — 종합소득세(단순경비율 → 기본공제 → 8단계 누진세율 → 지방소득세 → 기납부 3.3% 차감)와 건강보험료(요율 7.19% + 장기요양보험료, 직장/지역 구분), 연 2,000만원 기준 도달 전 경고.
  • 이상거래 탐지 — 규칙 엔진 7종 + Isolation Forest 앙상블. 화면에서 결제 상황을 지정해 즉시 판정(승인/본인확인/차단)을 받고 근거 규칙을 확인. 판정 결과는 탐지 이력에 기록됨.
  • 업무경비 자동 분류 — 생성형 AI가 거래를 업무/개인으로 분류하고 인정 확률을 산출, 예상 환급액 표시.
  • AI 브리핑 — 위 계산 결과를 생성형 AI가 2~3문장으로 설명하고 권고 한 줄 제시.
  • 수입 플랫폼 연결/해제 — 연결 시 해당 플랫폼 정산이 예측·세금 계산에 실제로 반영됨.
  • 예산 관리 — 카테고리별 한도 대비 사용률, 임계값 초과 표시.
  • Gig Score — 플랫폼 연결 성실도·지출 안정성·업무경비 인정률 기반 1000점 척도 지표.

3. 사용자 이용 흐름

  1. 배포 URL 접속 → 서비스 소개와 검증 수치, 시연 인물 3명의 카드가 보인다. 각 카드에 현금흐름 상태와 잔고 부족 예상일이 미리 표시되어 무엇을 보게 될지 알 수 있다.
  2. 인물 선택(예: 박지수 · 프리랜서 마케터) → 대시보드로 이동한다.
  3. 상단 요약과 AI 브리핑으로 현재 상황을 한 번에 파악한다. 바로 아래 할 일 카드에서 지금 조치할 항목을 확인한다.
  4. 현금흐름 탭에서 45일 예측 곡선을 보고, 시나리오 탭을 눌러 정산이 지연되면 부족 시점이 며칠 앞당겨지는지 확인한다. 오른쪽에서 5월 세금과 월 건보료를 확인한다.
  5. 수입 탭에서 미연결 플랫폼을 연결한다 → 정산 내역이 드러나고 예측·세금이 재계산된다.
  6. 지출 탭에서 예산 사용률과 AI가 분류한 업무경비 후보를 확인한다.
  7. 거래 보안 탭에서 상황 카드를 눌러 위험도 판정을 받아본다. 판정은 탐지 이력에 즉시 기록된다.
  8. 상단 "다른 사례 보기"로 돌아가 다른 인물의 상황과 비교한다.

4-2. 사용 데이터

  • 거래 내역 4,978건 / 35명 — 가맹점·금액·시각·국가·기기. 자체 생성한 가상 데이터(이상거래 정답지 포함).
  • 플랫폼 정산 내역 — 시연 인물별 3개 플랫폼, 90일치. 플랫폼명·유형·정산일·금액.
  • 제도 데이터 — 2026년 종합소득세 누진세율표, 건강보험료율 7.19%, 장기요양보험료율, 단순경비율, 피부양자 기준 2,000만원.
  • 사용자 설정 — 현재 잔액, 최소 안전잔액(화면에서 입력·수정).

4-3. 개인정보·민감정보 처리

실제 개인정보를 일절 수집·처리하지 않습니다. 로그인·회원가입이 없고, 실명·연락처·계좌번호·주민등록번호를 입력받는 화면이 존재하지 않습니다. 화면에 보이는 인물·거래·정산 내역은 전부 시연을 위해 생성한 가상 데이터이며, 공개된 시연 인물 3명 외의 데이터는 서버에서 접근을 차단합니다. 생성형 AI에 전달되는 값은 이미 계산이 끝난 수치와 가맹점명뿐이며 식별정보는 포함되지 않습니다.

5-2. 실행 환경 및 제한사항

  • 브라우저: Chrome·Edge·Safari 최신 버전 기준으로 확인했습니다. 별도 설치·계정·플러그인이 필요 없습니다.
  • 화면: 데스크톱 기준으로 설계했으며, 좁은 화면에서도 세로로 재배치되어 동작합니다.
  • 첫 접속 지연: 무료 호스팅 특성상 장시간 유휴 후 첫 요청이 지연될 수 있어, 서비스가 스스로 주기적으로 깨어 있도록 구성했습니다. 만약 첫 화면이 늦게 뜨면 잠시 후 새로고침해 주십시오.
  • 날짜 기준: 시연 데이터의 마지막 거래일(2026-08-22)을 "오늘"로 고정합니다. 실제 달력 날짜와 무관하게 심사 기간 중 항상 동일한 결과가 재현되도록 하기 위함입니다.

5-3. MVP 단계의 제한사항

  • 데이터: 오픈뱅킹·마이데이터 연동 전이라 잔액은 사용자가 입력한 값을 기준점으로 사용하며, 거래·정산 내역은 시연용 가상 데이터입니다.
  • 세금·보험료: 확정 금액이 아닌 추정치입니다. 인적공제·세액공제·타 소득, 건강보험료의 재산·자동차 점수는 반영하지 않았습니다.
  • Gig Score: 자체 정의 지표이며 금융기관의 신용점수가 아닙니다.
  • 인증: 공개 시연을 위해 로그인이 없습니다. 대신 공개된 시연 인물 3명 외의 데이터는 서버에서 접근을 차단하고 있으며, 실서비스 전환 시 세션 기반 인가가 선행되어야 합니다.
  • 생성형 AI: 외부 API에 의존하므로 일시적 장애 시 동일 수치의 규칙·템플릿 결과로 자동 대체됩니다 (기능이 중단되지 않으며, 표시되는 금액은 어느 경우에도 동일합니다).
